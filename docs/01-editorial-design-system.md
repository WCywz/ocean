# Editorial 视觉设计体系

## 背景

项目早期使用 Element Plus 默认的深色侧边栏 SaaS 风格（卡片 + 表格 + 标签组件）。这与海洋预报系统面向科研人员和环境管理者的定位不符，需要一套更权威、更沉稳的视觉语言。

## 设计决策

### 设计理念
采用"纸质出版物 Editorial"风格——通过字体层级和留白传递权威感和可读性，而非通过 UI 装饰（阴影、圆角、渐变色）。

### 色彩体系
- **主色调：** 灰白黑（monochromatic），不被任何品牌色绑定
- **强调色：** 红色（`#c0392b`）**仅用于告警**——项目中唯一的功能性色彩，不应被稀释
- **禁止使用：** 蓝色、紫色等与海洋科学主题无关的装饰性颜色
- **无玻璃态/毛玻璃效果**——过于潮流，缺乏权威感

### 字体体系
- **标题：** Georgia 衬线体（`--font-serif`），用于页面标题、统计数字
- **正文：** 系统无衬线字体，用于正文、表格、表单
- **标题类：** `editorial-page-title`、`editorial-section-heading`、`editorial-section-label`

### 组件风格
- **输入框：** 仅下划线样式，无边框圆角
- **表格：** 原生 `<table>` 元素替代 Element Plus `el-table`，细线分隔
- **卡片：** 无阴影，1px `#f0f0f0` 实线边框
- **按钮：** `editorial-btn-outline` 描边样式，无圆角

### 布局
- **顶部导航栏**替代左侧侧边栏，角色控制可见性
- **区域分隔**使用 section 标题 + 细线，而非卡片包裹

## 当前应用范围

Editorial CSS 类在 **21 个文件**中使用了 **168 次**，覆盖所有主要页面：
- 健康评估、观测数据、模型管理、预报地图、仪表盘、用户管理、登录注册等

全局引入方式（`App.vue`）：
```
import '@/styles/editorial.css'
import '@/styles/landing.css'
```

## 设计约束

- 颜色**严格**用于传达信息层级，非装饰目的
- 红色是唯一的强调色，保留给告警信息
- 新增页面必须遵循 Editorial 体系，使用全局 CSS 类而非自定义样式
