# 调度总览 — 拖拽排程

## 目标

将版本的 Cron 调度可视化，通过拖拽操作替代手动输入 Cron 表达式。

## 交互方案

1. 每个模型版本渲染为一张**可拖拽卡片**，卡片上显示基本信息（模型名、版本号、状态）
2. 页面上有一个**日历/时间轴视图**（类似 Google Calendar 的周视图或月视图）
3. 将版本卡片**拖拽到日历的时间槽位上**，即自动生成对应的 Cron 表达式
4. 一个版本可以有多个调度槽位（对应多条 Cron），也可以从日历上移除（删除调度）
