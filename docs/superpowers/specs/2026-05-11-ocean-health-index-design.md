# 海洋健康指数板块 设计文档

## 概述

新增"海洋健康指数"板块，以类似空气质量指数（AQI）的混合呈现方式展示预测结果解读。

- 核心问题：当前系统以数据网格、表格为主，非专业用户难以理解预测结果的含义和影响
- 目标：公众科普 + 决策辅助双用途，以等级/标签为主视觉，辅以自然语言解读
- 新增板块，现有功能全部保留

## 路由与入口

- 新路由：`/app/ocean-health`
- 左侧导航新增入口"海洋健康指数"
- 新增页面组件：`OceanHealthView.vue`
- 现有路由和组件零修改

## 分区规则

以一个参考点为中心，按方位和离岸距离两个维度自动分区，无需手动划定边界。

| 维度 | 方式 | 结果 |
|---|---|---|
| 方位 | 按参考点纬度线切分 | ≥参考纬度 = 北，<参考纬度 = 南 |
| 离岸距离 | 按经度到海岸线距离切分 | ≤0.5° = 近岸，0.5°-1.5° = 过渡带，>1.5° = 远海 |

分区参数：参考点经纬度 `centerLon`/`centerLat`、海岸线经度 `coastLon`（后续可配置化）。

结果：2(方位) × 3(距离) = 6 个子区域。后续扩展其他海域时只需更换参考点坐标和海岸线参考值。

## 等级体系

综合风险等级及各子指标等级分为 4 档，综合等级取各项最差值（类似 AQI 首要污染物）。

| 等级 | 颜色 | SST 异常标准 | 赤潮风险标准 | 海洋热浪标准 |
|---|---|---|---|---|
| 优 | 绿 #22c55e | ≤0.5°C 偏差 | Chl < 2.0 且趋势平稳 | 无 |
| 良 | 绿 #22c55e | 0.5-1.5°C | Chl < 3.0 或轻微上升 | - |
| 中 | 橙 #f59e0b | 1.5-2.5°C 或持续上升 | Chl ≥ 3.0 或明显上升 | - |
| 差 | 红 #ef4444 | >2.5°C 或热浪确认 | Chl ≥ 5.0 或爆发性增长 | 连续≥5天高于常年90分位 |

## 数据流

### 后端接口

```
GET /forecast/zone-health?centerLon=122.5&centerLat=29.5&coastLon=121.5&forecastDate=2026-01-01
```

**后端职责**（ZoneHealthController）：
1. 按方位/离岸距离规则计算各子区域坐标范围
2. 查询各子区域 SST 和 Chl 的均值、极值、趋势方向
3. 查询常年同期基准值，计算 SST 偏差
4. 检查海洋热浪条件（连续高温天数）

**返回结构**：

```json
{
  "zoneName": "东海",
  "zoness": [
    {
      "id": "nearshore-north",
      "label": "近岸北",
      "sst":  { "avg": 16.8, "max": 18.2, "trend": "rising",  "anomaly": 1.8 },
      "chl":  { "avg": 1.2,  "max": 2.1,  "trend": "stable" },
      "heatwave": { "active": false, "days": 0 }
    }
  ]
}
```

### 前端阈值引擎

工具函数 `buildZoneAssessment(zone)` 位于 `ocean-web/src/utils/health-assessment.js`：

- 输入：后端返回的子区域统计值
- 按阈值规则产出：综合等级、各指标等级、标签、自然语言解读文字、行动建议
- 完全在前端计算，阈值可方便调整

## UI 设计

### 页面结构

1. **顶部总览横幅**：综合结论摘要（如"东海海域：远海北部海洋热浪活跃，近岸区域总体正常"），附带预报日期
2. **卡片矩阵**：3×2 网格，每张卡片显示：
   - 区域名称（近岸北、过渡带北、远海北、近岸南、过渡带南、远海南）
   - 圆形等级标识（优/良/中/差 + 对应颜色）
   - 一句话结论
   - 子指标标签条（SST、Chl、热浪各一个状态标签）
3. **日期切换**：日期选择器，选不同日期的预报结果

### 交互行为

- 点击卡片 → 选中态高亮（蓝色边框），其余卡片变暗变灰
- 选中后该卡片所在行下方展开详情面板，包含：
  - 完整风险解读（自然语言段落）
  - 指标明细表（当前值、偏差、趋势、等级）
  - 行动建议列表
- 再次点击同一卡片或点击关闭按钮收起详情
