# 模型板块前端改造

## 目标

重构模型板块前端，引入侧边栏导航，拆分为 5 个子页面，提升信息架构清晰度和操作效率。

## 现状

- 模型板块仅有 2 个页面：模型管理（`/app/model`）、运行监控（`/app/model/monitor`）
- 运行监控没有导航栏入口，只能从模型管理页的小链接或告警铃铛进入
- 模型管理页用卡片展开/折叠管理版本，模型列表和版本管理耦合在同一个页面
- 告警只有铃铛下拉框，无独立列表页

## 设计方案

### 布局：顶部导航 + 侧边栏

- 顶部导航保留不动（仪表盘、预报、观测、健康、模型、用户）
- 进入模型板块后，左侧出现 200px 侧边栏
- 离开模型板块（进入预报、观测等页面）时侧边栏消失
- 风格：沿用 editorial 设计规范（Georgia 标题、灰色调、等宽按钮），兼容深色模式
- 侧边栏结构：
  - 分区标题「模型管理」
  - 菜单项：模型管理、调度总览、运行监控、告警管理、模型对比
  - 选中项：左边框高亮（`--color-text`），文字加粗
  - 分隔线后快捷操作区：+ 新建模型

### 子页面

#### 1. 模型管理（`/app/model`）

**列表页**：模型列表（表格或卡片），展示模型名称、类型、版本数量、运行中版本数、创建时间。筛选：模型类型下拉、名称搜索。操作：新增模型、编辑、删除。

**详情页**（`/app/model/:id`）：点击模型进入。包含模型基本信息编辑区 + 该模型下的版本列表 CRUD。版本列表展示：版本号、数据源、变更说明、状态。操作：新建版本、编辑、删除、启停。

**后端改动**：无。现有 `/api/model` 和 `/api/model/{id}/version` 接口已满足需求。

#### 2. 调度总览（`/app/model/schedule`）

**本次**：占位页，显示「调度总览」标题和开发中提示。

**后续规划**：拖拽排程——版本卡片拖拽到日历视图上自动生成 Cron 表达式。详见 `docs/ideas/调度总览-拖拽排程.md`。

#### 3. 运行监控（`/app/model/monitor`）

**本次**：纳入侧边栏菜单，路由保持不变。页面功能不变。

**Bug 修复**：列表中模型名称添加 `color: var(--color-text)` 确保可读性（已完成）。

**后端改动**：无。

#### 4. 告警管理（`/app/model/alerts`）

新建页面。

**功能**：
- 分页列表展示所有告警事件（模型名、版本号、告警类型、消息、时间、已读状态）
- 筛选：时间范围、模型名、告警类型、已读/未读状态
- 操作：标记已读（单条）、全部标记已读
- 点击告警可跳转到对应运行日志详情

**后端改动**：需要在 `AlertEventController` 新增分页查询接口（`GET /api/alert/page`），支持筛选参数（时间范围、模型 ID、告警类型、已读状态）。

#### 5. 模型对比（`/app/model/compare`）

**本次**：占位页，显示「模型对比」标题和开发中提示。

**后端改动**：无。

## 路由变更

| 路径 | 页面 | 变更 |
|------|------|------|
| `/app/model` | 模型管理（列表） | 重写 |
| `/app/model/:id` | 模型详情 + 版本管理 | 新增 |
| `/app/model/schedule` | 调度总览 | 新增（占位） |
| `/app/model/monitor` | 运行监控 | 保留，BUGFIX |
| `/app/model/alerts` | 告警管理 | 新增 |
| `/app/model/compare` | 模型对比 | 新增（占位） |

## 后端改动

仅告警管理需要新增分页查询接口：

```
GET /api/alert/page
参数: pageNum, pageSize, startTime, endTime, modelId, alertType, isRead
返回: IPage<AlertEventVO>
```

其余页面均复用现有接口，无需后端改动。
