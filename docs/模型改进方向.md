# 海洋预报模型改进方向

## 当前架构

- 双层 LSTM (256 units) + Multi-head Attention (8 heads) + 残差连接
- 18层深度剖面编码器 (DepthEncoder: TimeDistributed MLP)
- 空间特征分支 (lat/lon → MLP)
- 30天序列输入 → 7天预报
- 三个独立模型: CHL (叶绿素), SST (海温), SO (盐度)
- 损失函数: MSE
- 数据: ~8GB, StandardScaler 标准化

## 已知问题

### 1. CHL输入信息不足

CHL输入仅为表层1维特征，但其动态受营养盐、光照、混合层深度等多因素驱动。这些变量不在输入中，模型只能靠温盐数据间接推断生物过程，存在严重的信息瓶颈。

**可能方向**: 引入海面高度(SSH)、风场、光合有效辐射(PAR)等遥感数据作为额外输入特征。

### 2. 时序池化过于粗暴

当前使用 `x.mean(dim=1)` 将30个时间步等权平均为一个向量。最近的时间步对7天预报的参考价值应远高于30天前的时间步。

**可能方向**: 替换为最后K个时间步的 attention pooling，或直接取最后的 hidden state；也可尝试可学习的时序权重。

### 3. CHL 使用 MSE 损失不合适

CHL在近岸区域可比开阔大洋高1-2个数量级，MSE会被高值样本主导，导致模型偏向拟合高值区域而忽略低值区域。

**可能方向**: 对 target 做 log1p 变换后训练，预测时再 expm1 还原；或换用 MSLE (Mean Squared Logarithmic Error) 损失。

### 4. 空间特征介入过晚

经纬度信息通过一个小MLP后在最后一层才与LSTM输出拼接。模型无法在时序建模阶段学习不同海域的不同动力学模式（如近岸 vs 开阔大洋的预报逻辑完全不同）。

**可能方向**: 将空间编码作为额外特征在每个时间步注入LSTM输入；或使用空间显式的图神经网络/CNN结构。

### 5. 物理约束缺失

纯数据驱动方法缺乏物理规律约束（如质量守恒、能量守恒），在数据稀疏或极端事件时容易产生不符合物理规律的预报。

**可能方向**: 引入物理信息网络(PINN)思想，在损失函数中加入物理约束项；或使用数值模式输出作为辅助训练信号。

---

> 注意: 海洋预报本身是三维流体动力学问题，全球业务化系统(ROMS、HYCOM等)运行在超算上并依赖物理方程。纯ML方法在该领域尚无成熟方案，上述问题多为领域共性难题而非实现缺陷。
