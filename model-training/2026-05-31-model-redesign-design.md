# 模型重设计：表层输入 → 全 3D 预报

## 问题

现有模型训练使用 MY 再分析数据的 18 层温盐剖面作为输入，但生产环境 NRT 产品仅提供表层数据（SST/CHL/SSS/SSH）。模型无法在生产环境运行。

## 设计目标

- **输入**：仅 NRT 每日可获取的表层变量（SST、CHL、SSH、SSS、风应力旋度 + 60 天历史序列）
- **输出**：未来 1d/3d/5d/7d 的全 3D 场（18 层温度 + 18 层盐度 + 表层 CHL），支持预报图和侧剖图
- **物理约束**：保留上升流信号——通过 SSH（温跃层位移积分量）和风应力旋度（Ekman 抽吸驱动力）

## 整体架构：两阶段模型

```
CMEMS NRT (每日) → 3D U-Net 重建器 → PhyLSTM 预报器 → forecast_grid
                     ↑                     ↑
              阶段 1: 表层→当前3D      阶段 2: 3D序列→未来3D
```

两阶段可独立训练、独立验证。先验证阶段 1 重建质量，通过后再串联阶段 2。

## 阶段 1：3D 重建器

### 模型：3D U-Net

### 输入
| 变量 | 维度 | 来源 |
|------|------|------|
| SST | [H, W, 1] | CMEMS NRT 物理产品 |
| CHL | [H, W, 1] | CMEMS NRT BGC 产品 |
| SSH | [H, W, 1] | 卫星高度计 |
| 风应力旋度 | [H, W, 1] | 大气模式 |
| SSS（可选） | [H, W, 1] | CMEMS NRT 物理产品 |

### 输出
| 变量 | 维度 |
|------|------|
| 温度剖面 | [18, H, W] |
| 盐度剖面 | [18, H, W] |

### 训练数据

使用 CMEMS MY 再分析产品（`cmems_mod_glo_phy_my_0.083deg_P1D-m` + `cmems_mod_glo_bgc_my_0.25deg_P1D-m`），同一时刻的表层字段作为输入、全深度剖面作为标签。区域：东海 121.33°E–125.58°E, 26.92°N–32.67°N。

### Loss

垂向分层 MSE + 温跃层附近加权 MAE，强化对上升流垂直梯度的学习。

### 验证标准

重建的深层温盐与真值的相关性 > 0.7（千问建议阈值）。若 < 0.5，说明表层输入信息不足，需补充驱动因子。

## 阶段 2：PhyLSTM 预报器

### 模型：PhyLSTM + 多头自注意力 + 多任务头

参考千问方案，隐状态显式划分为"表层模态"和"深层模态"，训练时用底层真值单独监督深层模态。

### 输入

60 天 × 重建的全 3D 场（18 层温度 + 18 层盐度 + 表层 CHL）+ 网格点经纬度。

### 输出（多任务头）

4 个时次 × (18 层温度 + 18 层盐度 + 表层 CHL)：
- 1d（预警）
- 3d（日常监测）
- 5d（规划）
- 7d（趋势 + 侧剖图）

### Loss

时间衰减加权 MSE：近 days 权重高（1d=1.0, 3d=0.8, 5d=0.5, 7d=0.3），反映可预报性衰减。

### 训练策略

1. Teacher Forcing 衰减：训练初期用上一时刻真值输入，后期逐步切换到模型自身预测
2. 多任务辅助：同时预测深层模态，即使推理时主要关���表层

## 数据流（生产环境）

1. 每日 00:05 SystemDateTask 触发
2. `download_cmems.py` 拉取最新 NRT 表层数据（SST/CHL/SSH/风场）
3. 3D U-Net 重建器从表层重建当前 18 层温盐
4. PhyLSTM 预报器接收 60 天重建序列，输出 4 时次全 3D 场
5. 写入 forecast_grid，支持前端预报图、侧剖图、健康评估

## 数据源

| 用途 | 产品 | 数据集 ID |
|------|------|-----------|
| 训练 | MY 再分析 | `cmems_mod_glo_phy_my_0.083deg_P1D-m` + `cmems_mod_glo_bgc_my_0.25deg_P1D-m` |
| 推理 | NRT 近实时 | `cmems_mod_glo_phy_nrt_0.083deg_P1D-m` + `cmems_mod_glo_bgc_nrt_0.25deg_P1D-m` |

训练-推理数据分布差异通过以下方式缓解：
- 重建器和预报器均在 MY 数据上训练
- 推理时仅输入表层，MY 和 NRT 的表层数据分布差异远小于深层
- 若 NRT 表层与 MY 表层存在系统性偏差，可对 NRT 输入做简单的均值-方差校准

## 训练环境

| 硬件 | 规格 |
|------|------|
| GPU | RTX 4070 Laptop 8 GB |
| RAM | 32 GB |
| CPU | i7-14700HX |

网格仅 391 个点（23×17），18 层深度，模型参数量不大。8 GB 显存可通过小 batch size + gradient accumulation 解决。

## 区域与分辨率

| 参数 | 值 |
|------|-----|
| 经度 | 121.33°E – 125.58°E |
| 纬度 | 26.92°N – 32.67°N |
| 网格分辨率 | 0.083°（物理）/ 0.25°（BGC）→ 统一到 0.25° |
| 深度层 | 18 层（0.5m – 47.4m） |

## 两阶段模型（1 周极限）

### 时间估算

| 阶段 | 内容 | 时间 |
|------|------|------|
| Phase 1 | 3D U-Net 重建器训练 + 验证 | 2-3 天（含数据准备） |
| Phase 2 | PhyLSTM 预报器训练 + 验证 | 2-3 天 |
| Phase 3 | 两阶段串联 + 端到端测试 | 1 天 |
| Phase 4 | 接入生产管道 | 0.5 天 |

前提：GPU 24GB+ 显存（如 RTX 3090/4090/A10），MY 再分析数据已就绪。

### Phase 1：3D U-Net 重建器
- 训练目标：深层相关性 > 0.7
- 若 < 0.5：补充输入特征或调整网络深度

### Phase 2：PhyLSTM 预报器
- 对比有/无真实深层输入的预报技巧差异
- 达标后进入串联

### Phase 3：两阶段串联端到端测试
- 全链路验证：NRT 表层 → 重建 3D → 预报 3D → 对比真值

### Phase 4：接入生产管道
- SystemDateTask → download_cmems.py → 重建推理 → 预报推理 → forecast_grid
